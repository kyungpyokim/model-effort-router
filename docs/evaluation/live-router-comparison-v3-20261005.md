## 결과 해석

- **Nimble:** 합본 79.2%→82.1%지만 새 표본은 78.5%→76.7%다. 새 L4/L5는 개선됐으나 새 L2는 78.0%→65.3%로 하락했다. 합본 상승만으로 보강 질문의 일반화를 확인할 수 없다.
- **L2 리뷰:** 기존 질문은 과대 24건(22건 L3, 2건 L4)·과소 2건, 보강 질문은 과대 45건(모두 L3)·과소 1건이다. 두 조건의 모든 리뷰 오답은 raw argmax와 최종 레벨이 같다. 이 구간의 오답은 후처리 승격으로 새로 만들어진 것이 아니다. 모델 내부 추론이나 특정 단어의 인과 효과는 측정하지 않았다.
- **Jev:** 새 L2는 98.7%→100%지만 새 전체는 97.4%→96.3%다. 새 L4/L5에서 회귀가 있으며, 합본 critical miss도 0→2건으로 늘었다.
- **코퍼스 확대는 재학습이 아니다.** 고정한 모델과 질문을 더 많은 사례로 측정한 결과다. 새 데이터로 질문·임계값을 조정하지 않았으며, 보강 질문을 제품에 채택하지 않았다. 다음 후보는 이 결과를 본 뒤 조정한다면 별도 표본으로 검증해야 한다.

## 실행과 재현

같은 seed(20261005)로 입력 순서를 섞고, 각 backend 안에서는 기존→보강 순차 실행했다. Jev와 Nimble은 병렬 실행했지만 같은 backend의 두 조건은 겹치지 않았다. 분류기에는 요청 원문과 경로만 전달했으며, 요청에 포함된 짧은 코드 외에 실제 저장소 코드나 diff를 추가하지 않았다.

보강 조건은 이전에 고정한 `runs/live-guide-level-question-20261004.json`을 transport wrapper에서 level 질문에만 적용했다. 나머지 질문의 동일성과 입력의 완전 일치를 호출마다 assert로 검증했다. 모델·위험 임계값·레벨 후처리는 제품 코드를 그대로 사용했다. 보강 조건은 실험이며 제품의 기본 질문은 기존 질문이다.

전송한 모델 식별자는 Jev `jev-latest`, Nimble `nimble`이었다. 실행기 코드의 독립 검토와 질문 해시 검사 보강을 완료했다. 최종 결과의 추가 검토 에이전트는 워크스페이스 크레딧 부족으로 중단됐으며, 표·부분집합 집계·전송 기록·해시 대조는 메인 세션이 직접 검증했다.
