# 개선 후보 실제 호출 검증 — 2026-10-05

**696회 새 live 호출 완료: 조건부 Jev 후보는 사전 기준을 통과했고, 구현 표현 접두어 후보는 탈락했다.** 모든 응답 HTTP 200, 오류·불완전 판정 0건이다. 제품 코드·플러그인·설정·질문·코퍼스는 변경하지 않았다.

새 합성 진단 300개를 사용했다. 난이도 평가 270개, target 평가 300개다. 이미 앞선 평가에서 확인한 표본이며 실제 요청 holdout이나 사람의 독립 정답 검증이 아니다. 이번 결과는 후보 검증이며 제품 적용 결정이 아니다.

## 조건부 Jev 연쇄 호출

Nimble을 먼저 호출하고, 기존에 고정한 다음 조건 중 하나에 해당하면 Jev를 실제로 추가 호출했다: raw 최고 확률 <0.60, 상위 두 확률 차이 <0.15, 예측 target이 plan/review, backend 또는 규칙 기반 위험 감지. 임계값·선택 규칙을 조정하지 않았으며, 두 단계 모두 기존에 고정한 guide level 질문을 사용했다. 선택된 경우 Jev 판정을 최종값으로 사용했다.

실행 전 고정한 기준(각 레벨 ≥80%, critical miss ≤2, 불완전 판정 0)을 통과했다. 재생 예측 259/270과 실제 호출 260/270은 1건 차이가 있으므로 재생 점수를 live 점수로 대신하지 않았다. 최종 오답 10건은 모두 과소평가다. Nimble의 정답을 Jev가 오답으로 바꾼 5건은 `fresh-179`, `fresh-287`, `fresh-190`, `fresh-162`, `fresh-075`다.

선택 사유는 scoped 143건, risk 105건, uncertain 68건이며 중복된다. 미선택 88건의 p50/p95는 1,209.7/1,421.2 ms, 선택 212건은 1,457.4/1,739.4 ms다. p95는 정렬값의 `floor(.95*(n-1))` 위치로 계산했다. 각 요청의 연쇄 실행 시간을 재었으며 뒤이은 표현 실험 호출은 포함하지 않는다.

Jev 단독 300회 대비 Jev 호출 수는 29.3% 줄지만 Nimble 300회가 추가된다. **총 비용 절감이나 속도 이점을 입증한 결과는 아니다.** 앞선 별도 실행의 Jev baseline은 263/270(97.4%)였으므로 정확도만을 목표로 할 때 이 연쇄가 Jev 단독보다 우수하다고 볼 수 없다. 이번 실행에는 Jev 단독 전체 표본을 다시 호출하지 않았다.

## 구현 표현 접두어: 쌍 비교

정답 target이 review_only인 92개를 진단용으로 선택했다: L2 60개와 L1/L3/L4/L5 대조군 32개. 각 원문을 새로 호출한 뒤, 아래 고정 접두어와 원문 전체를 연결해 다시 호출했다. 경로·코드·원문은 그대로 보존했고 정답 레벨을 입력하지 않았다. 질문은 제품 baseline을 사용했다. 원문 호출의 target·위험 플래그를 보존하고 두 번째 호출의 난이도만 결합했다.

```text
Implement the change described below. Retain all stated code, behavior, scope, architecture constraints and verification requirements. Treat instructions limiting the activity to inspection as context for the original request, not as limits on implementation difficulty.

Change description:
```

이는 리뷰 문장을 제거하거나 요구사항으로 재작성한 실험이 아닌 **접두어 개입**이다. 원문의 리뷰 지시가 남아 있으므로 의미를 완전히 분리한 입력으로 해석하지 않는다.

| 정답 | n | 새 원문 호출 | 접두어 추가 |
|---|---:|---:|---:|
| L1 | 6 | 4/6 | 4/6 |
| **L2** | **60** | **33/60 (55.0%)** | **29/60 (48.3%)** |
| L3 | 8 | 8/8 | 8/8 |
| L4 | 9 | 3/9 | 5/9 |
| L5 | 9 | 9/9 | 8/9 |
| 전체 | 92 | 57/92 (62.0%) | 54/92 (58.7%) |
| L2 이외 대조군 | 32 | 24/32 (75.0%) | 25/32 (78.1%) |

L2는 오답→정답 3건, 정답→오답 7건으로 순변화 -4건(-6.7%p)이다. McNemar exact 양측 p=0.34375이며 통계적으로 악화를 확정할 수는 없다. 그러나 사전 기준인 L2 ≥80%, 개선 ≥10%p를 충족하지 못하므로 **이 후보는 채택하지 않는다.** 대조군 순변화 +1건과 불완전 판정 0건 기준은 충족했다. 두 조건의 critical miss는 0/46이다.

target은 두 조건 모두 66/92로, 결합 과정에서 모든 target·위험 플래그를 보존했음을 확인했다. 원문 p50/p95는 943.9/1,059.4 ms, 접두어 호출은 1,055.5/1,233.9 ms다. 이 값은 각 호출의 시간이며 두 번 호출하는 후보의 전체 지연시간이 아니다.

모든 쌍에서 원문을 먼저 호출했으므로 순서·서버 상태 효과를 배제하지 못한다. 또한 gold review_only 선택은 진단용 선택이므로 제품의 자동 선택 성능을 의미하지 않는다. 이 실패는 모든 의미 분리 방법의 실패를 증명하지 않지만, 같은 접두어 실험을 확대할 근거는 주지 않는다.
