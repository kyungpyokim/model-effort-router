# 경계 사례 40건과 평가 결론 검토 — 2026-10-05

**코퍼스 경계 판단도 점수에 영향을 주고 있다. 그러나 Nimble의 잔여 과소 판정과 새 L2 질문의 회귀는 라벨 이슈만으로 없어지지 않는다.** 기존 정답·예측을 가린 두 AI 검토 결과를 비교하고 점수 민감도를 계산했다. 코퍼스 정답, 질문, 제품 설정은 수정하지 않았다.

## 검토 결과

- 두 독립 AI 검토자: 40건 중 level/risk/target 완전 일치 39건(97.5%), 불일치 1건(seed-036). 2단계 이상 레벨 불일치 없음.
- 두 검토자가 함께 기존 정답과 다르게 판단한 사례: 레벨 6건, 위험 플래그 3건. 별도로 seed-036에서 한 검토자가 기존 레벨에 이견을 냈다. 따라서 기존 라벨에 이견이 제기된 사례는 총 10건이다.
- 어느 한 검토자라도 ambiguous를 표시한 사례 11건. target은 두 검토자 모두 기존 40건과 일치했다.
- 기존 정답과의 완전 일치는 A 30/40, B 31/40; 레벨만 일치는 A 33/40, B 34/40. 이 표본은 경계·오답에 치우쳐 선정했으므로 코퍼스 전체의 오류율로 환산하지 않는다.
- 검토자는 labeling-guide와 blind task/paths만 읽었다. 서로의 판단과 기존 corpus·예측은 읽지 않았다. 다만 가이드 자체에 과거 개별 사례의 합의 예시가 있으므로 완전한 정답 비노출 실험이나 사람 검증으로 부르지 않는다. 같은 모델 계열의 두 AI 판단이 같은 오류를 가질 가능성도 남는다.

## 레벨 제안 6건을 모두 반영한 민감도

공식 정답은 보존했다. 아래는 두 AI가 같은 다른 레벨을 제안한 6건을 **전부** 임시 반영했을 때 저장 예측을 재채점한 가정이다. 위험 플래그는 바꾸지 않았다. 새로운 모델 호출이나 독립 성능 검증이 아니다. 원래 250건 중 L2 49건이 이 시나리오에서는 45건이 된다.

- 그래도 이전 보강 Nimble의 critical은 6→5건이고, 새 L2 문구는 전체 85.6%·L2 77.8%·critical 7건으로 남는다. 이전 보강 89.2%·critical 5건보다 나쁘므로 **새 L2 문구를 기각한 결론은 유지된다.**
- guide Jev/위험 포함 hybrid는 기존에 add-041만 critical이었다. 위 시나리오에서는 add-041이 빠지는 대신 exp-014(L3로 바뀐 업로드 검토를 L2로 예측)가 들어와 critical 1건이 유지된다. 위험 포함 hybrid 전체는 94.8%→94.4%, 모든 레벨은 여전히 80% 이상이다.
- 불확실 사례만 Jev로 보내는 규칙은 기존 라벨에서 critical 3건으로 실패했지만 이 가정에서는 2건이 된다. 합격 여부가 경계 라벨에 민감하므로 지금 가장 호출 수가 적은 규칙을 고르는 데 이 시나리오를 사용하지 않는다.

## 실험 결론 검토

- 여섯 hybrid 재생 조합에서 선택 ID 수, 각 사례의 선택된 backend, 전체·레벨별 정답 수를 검산했다. 보고서의 산술 오류는 발견하지 못했다.
- raw argmax에서도 Nimble 이전 보강 215/250(86.0%)→새 L2 질문 209/250(83.6%)로 내려갔다. 이번 회귀는 후처리 임계값만의 현상이 아니다. 다만 질문 문구 하나가 실제로 어느 내부 판단을 바꿨는지는 모델 추론 로그 없이 확정하지 않는다.
- 94.8%와 Jev 호출 44% 절감은 기존 라벨에서의 재생 수치다. 실제 순차 호출의 지연·실패 처리와 사람 검증을 마친 운영 성능으로 발표하면 안 된다. 새 실제 요청의 독립 평가가 필요하다.
- 현재 판단: 새 L2 질문 기각은 타당하다. 위험 포함 hybrid는 후속 검증 후보로 유지한다. L2 경계·정보가 부족한 리뷰 사례·auth의 인증/인가 범위를 명시한 뒤 독립 재라벨링을 진행하는 것이 우선이다.
